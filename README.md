# Reality VPN App

A modern Android VPN client supporting VLESS Reality, VMess, Trojan, and Shadowsocks protocols.

## Features
- **VLESS Reality Support**: High-performance, stealthy VPN protocol.
- **Cyberpunk UI**: Modern, high-tech interface with real-time monitoring.
- **Protocol Support**: VLESS, VMess, Trojan, Shadowsocks.
- **Live Monitoring**: Real-time speed and bandwidth tracking.
- **Server Management**: Easy import and management of VPN nodes.

## Build Instructions
1. Clone the repository.
2. Open in Android Studio.
3. Build the project using Gradle.

## Disclaimer
This project is for educational purposes and intended as a UI/UX showcase for a VPN client.
